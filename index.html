⚙️ How QR-VISION Works

1️⃣ QR Code → Attached to the vehicle number plate

2️⃣ Scan → Opens the digital vehicle profile

3️⃣ Identification → Vehicle information is displayed

4️⃣ GPS → Vehicle location can be monitored

5️⃣ Geofence → System detects if vehicle leaves the safe area

6️⃣ Emergency → Alert can be generated

7️⃣ Accident Detection → Future sensors/AI can detect possible accidents
